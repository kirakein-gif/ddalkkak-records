# transfer

## 기록물이관신청서 자동화

K-에듀파인 문서등록대장을 입력받아 기록유형을 분류하고 편철한 뒤 이관신청서와 기록물관리 연계 데이터를 생성하는 웹 앱.

## 현재 상태

**v0.2 Beta · 실제 파일 검증 단계**

현재 GitHub Pages 배포본:
- 문서등록대장 Excel/CSV 업로드
- 비전자 대상 검증
- 기록유형 자동분류 및 사용자 보정
- 일반문서 100쪽 기준 자동편철
- 일반문서 외 1문서 = 1권
- 제외/복원, 순서 이동, 수동 분권
- 이관 Excel 생성
- 숨김 `_handoff`, `_handoff_docs` 생성

이관신청 자동화의 핵심은 **편철 자동화**다.

현재 Beta에서는 실제 K-에듀파인 파일의 열 인식, 유형분류, 편철 경계, 생성 Excel, 기록물대장관리 연계를 우선 검증한다.

결재첨부용 이관신청서의 표시양식은 실제 사용 검증 후 최종 고정한다.

자세한 테스트 기준은 `docs/beta-test-plan.md`를 따른다.

# migration

## 기존 기록물관리대장 표준전환

지역별로 파편화된 과거 기록물관리대장을 충청남도교육청 표준양식으로 변환하는 웹 도구.

현재 HTML 프로토타입에서 검증된 핵심 개념:
- 학교/직속/기록관 표준서식 선택
- 원본 대장 헤더 자동 탐지
- 표준 필드 자동 매칭
- 드래그 방식 수동 보정
- JSON 매핑 저장
- 표준 Excel 출력

향후에는 JSON을 단순 열 매핑이 아니라 값 변환·분해·결합·검증까지 포함한 '지역 변환 프로필'로 확장한다.


## v0.1 방향 확정 — 기존 대장 표준화

마이그레이션은 신규 기록물 이관이 아니라 지역·기관별로 파편화된 기존 기록물관리대장을 하나의 표준 내부구조로 맞추는 기능이다.

핵심 원칙:
- 기존 관리번호, 상자번호, 위치정보, 철제목은 재계산하지 않고 원본값을 보존한다.
- 원본에 없는 표준 필드는 추측해서 생성하지 않고 공란으로 둔다.
- 확실한 표현 차이만 안전하게 정규화한다.
- 기관 전체에 공통이며 사용자가 확정한 값은 기관/마이그레이션 프로필로 보충할 수 있다.
- 모든 원본 열은 표준서식에 사용되지 않더라도 변환 추적정보에 남긴다.
- 한 번 확정한 헤더 매핑은 헤더 서명(signature) 기반 프로필로 재사용한다.

값의 계보(status):
- source: 원본값 그대로
- norm: 안전한 자동 정규화
- profile: 기관/프로필 공통값으로 보충
- manual: 사용자가 매핑을 직접 보정
- missing: 원본정보 없음

v0.1 프로토타입은 표준서식 종류 선택 → 대장 업로드/샘플 → 자동 헤더 탐지 → 열 매핑 → 기관 공통값/정규화 → 상태별 미리보기 → 표준서식 Excel/추적 JSON/프로필 JSON 출력 흐름으로 구성한다.

## v0.2 — 가로형 드래그앤드롭 매핑 UI

열 매핑 화면을 세로 셀렉트 방식에서 실제 표준대장 열 배치와 유사한 가로형 드래그앤드롭 방식으로 변경한다.

흐름:
1. 프로그램이 원본 헤더를 1차 자동매칭한다.
2. 표준대장 필드는 실제 열 순서대로 좌→우로 펼친다.
3. 자동매칭된 원본 열은 해당 표준필드 칸 안에 카드로 표시한다.
4. 미매칭 원본 열은 하단 바구니에 모은다.
5. 사용자는 원본 열 카드를 원하는 표준필드로 드래그해 보정한다.
6. 기존 배정 카드를 다른 칸으로 옮길 수 있고, × 또는 하단 바구니로 끌어 매핑을 해제할 수 있다.
7. 최종 매핑을 저장하면 같은 헤더 서명에서 마이그레이션 프로필로 재사용한다.

UX:
- 자동 정확매칭 / 자동 유사매칭 / 사용자·프로필 / 표준필드 미충족을 색으로 구분
- 표준필드 미충족 칸을 강조
- '첫 미매칭 칸으로' 이동 기능
- 드래그 중 좌우 가장자리에 접근하면 가로 스크롤
- 원본 값 예시를 카드에 표시
- 표준서식에 매칭하지 않은 원본 열도 추적정보에는 보존

## v0.3 매핑 샘플 미리보기

드래그 매핑 화면에서 원본 열을 표준 필드에 놓으면 해당 원본 열의 실제 앞 3개 데이터 행을
표준 필드 아래 미니 표 형태로 즉시 표시한다.

목적:
- 헤더명만 보고 매핑하지 않고 실제 값 형태를 함께 확인
- 전체 원본 데이터를 펼치지 않고도 대표 샘플 3건으로 빠르게 판단
- 잘못된 자동매핑이나 사용자 보정을 즉시 발견

표시 원칙:
- 실제 원본의 앞 3개 데이터 행 사용
- 빈 값도 '(빈 값)'으로 표시하여 실제 붙는 모습을 숨기지 않음
- 미리보기는 판단 보조이며 변환 데이터 자체를 변경하지 않음
- 최종 매핑은 기존과 동일하게 프로필로 저장 가능


## v0.4 1차 통합 기준

지금까지 확정한 마이그레이션 기능을 하나의 기준 흐름으로 통합했다.

흐름:
1. 학교/직속기관/기록관 표준서식 선택
2. 기존 기록물관리대장 업로드 또는 샘플 실행
3. 대상 시트와 헤더 자동 탐지
4. 원본 열을 표준 필드에 1차 자동매핑
5. 표준대장 실제 열 순서의 가로형 드래그 매핑
6. 각 매핑 칸 아래 원본 앞 3건 샘플 표시
7. 미매칭 원본 열은 하단 바구니에 유지
8. 사용자가 드래그로 보정한 최종 매핑을 프로필로 저장
9. 기관 공통값과 안전한 정규화 적용
10. 원본/정규화/기관보충/사용자매핑/정보없음 출처상태 표시
11. 표준서식 변환 및 추적정보 출력

고정 원칙:
- 마이그레이션은 신규 기록물 이관이 아니라 기존 지역별/기관별 대장 표준화다.
- 기존 관리번호, 상자번호, 위치정보, 철제목을 재계산하지 않는다.
- 원본에 없는 표준 필드는 공란으로 둔다.
- 확실한 표현 차이만 자동 정규화한다.
- 표준서식에 없는 원본 열도 추적정보에서 버리지 않는다.
- 프로필에는 실제 기록물 행 데이터가 아니라 헤더 매핑과 기관 공통설정만 저장한다.

v0.4를 이후 지역별 실제 대장 테스트의 1차 기준선으로 사용한다.


## v0.5 매핑 편집기

단순한 1:1 열 매핑에서 “원본 열 재료 + 표준필드별 변환 규칙” 구조로 확장한다.

- 같은 원본 열을 여러 표준필드에서 반복 사용 가능
- 한 표준필드에 여러 원본 열을 드롭하면 기본적으로 합치기 규칙을 사용
- 표준필드별 값 편집 지원:
  - 그대로 사용
  - 구분자로 나누기(첫번째/마지막/지정번째)
  - 앞/뒤 N글자 자르기
  - 문자 찾기/치환
  - 숫자만 추출
  - 4자리 연도 추출
  - 여러 원본 열 합치기(구분자 지정)
- 편집창에서 원본 앞 3건을 원본값 → 변환값 형태로 실시간 미리보기
- 원본 데이터 자체는 수정하지 않고 출력값에만 규칙 적용
- 변환 규칙까지 마이그레이션 프로필에 저장
- v0.4 이하 단순 매핑 프로필은 호환해서 읽음

프로필 v5에서는 단순 mapping 배열 대신 targetEn + sourceHeaders[] + transform 구조의 bindings를 사용한다.

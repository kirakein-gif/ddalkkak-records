# 기록물관리 출력 템플릿

출력 규격이 중요한 산출물은 프로그램이 새로 그리지 않고 검증된 Excel 원본 템플릿을 사용한다.

## 구조

```text
templates/
├─ management/
│  └─ 관리출력양식_원본.xlsx
└─ standard-ledger/
   ├─ 기록물관리대장_학교.xlsx
   ├─ 기록물관리대장_직속.xlsx
   └─ 기록물관리대장_기록관.xlsx
```

## management 원본

기존 `기록물관리대장 자동화_v19(리디자인).xlsb`의 **양식** 시트를 Microsoft Excel 자체의 Worksheet.Copy로 한 번 추출해 `관리출력양식_원본.xlsx`로 보관한다.

이 파일에서 사용하는 출력물:
- 기록물철 표지
- 색인
- 관리번호 스티커
- 보존상자 라벨

관리번호 스티커와 보존상자 라벨은 규정 형식이므로 셀 병합, 행높이, 열너비, 글꼴, 테두리, 인쇄 설정을 임의 변경하지 않는다.

기록물철 표지는 보존용 서류철에 맞는 원본 위치를 유지하되 실물 출력 검증 후 미세 조정만 허용한다.

## 표준 기록물관리대장

학교/직속/기록관용 공식 Excel을 각각 템플릿으로 보관한다.

프로그램은 해당 기관 프로필의 유형에 따라 템플릿을 선택하고 원본 서식을 유지한 채 지정 데이터 영역에만 값을 입력한다.

## 배포 원칙

운영 시 매 실행마다 GitHub에서 원격 다운로드하는 구조보다는, 배포 시 해당 버전의 템플릿을 앱과 함께 캐시/포함하여 네트워크 장애에도 출력 가능하도록 한다. GitHub는 원본 및 버전관리 기준 저장소로 사용한다.


## 템플릿 원본 출처 확정

기존 자동화 파일을 기준으로 출력 템플릿의 출처를 분리한다.

### 기록물이관신청서 자동화_v20(기록물종류변세분화).xlsb
- `표지(서식)` → 기록물철 표지 템플릿 원본
- `색인목록(서식)` → 색인 템플릿 원본
- `이관신청서(서식)` → 구형 이관신청서 참고 원본(신규 웹버전은 별도 확정 서식 사용)

`색인목록(서식)` 확인 헤더:
- 일련번호
- 일자
- 등록번호
- 제목
- 보낸기관
- 받은기관
- 쪽표시
- 전자문서 여부
- 비고

### 기록물관리대장 자동화_v19(리디자인).xlsb
- 관리번호 스티커 원본 규격/생성로직
- 보존상자 라벨 원본 규격/서식

### 공식 표준대장
- `기록물관리대장 서식(학교).xlsx`
- `기록물관리대장 서식(직속).xlsx`
- `기록물관리대장 서식(기록관).xlsx`

원칙: 원본 규격이 존재하는 출력물은 새로 디자인하지 않고 해당 Excel 원본을 템플릿으로 사용하며 프로그램은 데이터만 주입한다.


## 2026-09-22 기준 원본 템플릿 확정

사용자가 GitHub `templates/`에 실제 운영용 Excel 양식을 업로드했으므로,
아래 파일을 최종 출력의 기준 원본으로 사용한다.

- `표지(서식).xlsx`
- `색인목록(서식).xlsx`
- `관리번호스티커(서식).xlsx`
- `상자라벨(서식).xlsx`
- `기록물관리대장 서식(학교).xlsx`
- `기록물관리대장 서식(직속).xlsx`
- `기록물관리대장 서식(기록관).xlsx`

이후 프로그램은 위 서식을 새로 그리지 않는다.
원본 파일을 복제하고 지정된 셀/행에 최종 데이터만 주입한다.

특히 관리번호 스티커와 상자라벨은 규정 형식으로 취급하여
열너비, 행높이, 병합, 글꼴, 테두리, 인쇄영역 및 페이지 설정을 프로그램이 임의 변경하지 않는다.

표지와 색인 역시 이 업로드본을 기본 원본으로 사용하며,
표지는 실제 보존용 서류철과의 물리적 맞춤을 위한 미세 조정만 허용한다.

마이그레이션 원칙 · 신규 기록물을 받는 기능이 아니라, 기존에 각 지역·기관에서 사용하던 대장을 표준 구조로 맞추는 기능입니다. 기록연구사는 확정한 작업방식을 JSON으로 배포하고, 학교는 그 JSON을 불러온 뒤 기존 대장만 넣어 같은 기준으로 변환할 수 있습니다.
역사값은 보존기존 관리번호·상자번호·위치정보·기록물철 제목은 임의로 다시 만들지 않습니다.
분류값은 표준화단위과제·보존기간·기록유형은 표준양식의 단위과제표와 유효성검사를 기준으로 검증·보정합니다.
틀린 값은 통과시키지 않음6년·7년·8년 같은 비표준 보존기간은 그대로 출력하지 않고 표준 근거를 찾거나 검토필요로 표시합니다.
원본과 근거를 함께 추적보정 전 원본값, 보정값, 표준 근거, 원본 파일·시트·행을 추적정보에 남깁니다.

원본 열 → 표준대장 열 매핑

표준대장의 실제 열 순서대로 가로로 펼쳐집니다. 원본 열은 재료처럼 여러 표준필드에 반복해서 사용할 수 있고, 각 표준필드에서 나누기·자르기·치환·합치기 규칙을 편집할 수 있습니다.
사용법 아래 ‘원본 열 재료함’의 카드를 표준 필드 칸으로 끌어다 놓습니다. 같은 원본 열을 여러 칸에 놓아도 원본은 사라지지 않습니다.‘값 편집’에서 앞 3건의 변환 결과를 즉시 확인합니다.이미 배정된 카드도 다른 칸으로 이동할 수 있습니다. ×를 누르거나 아래 바구니로 다시 끌면 매핑이 해제됩니다.
자동 정확매칭 자동 유사매칭 사용자/저장 작업방식 표준필드 미충족
원본 열 재료함
모든 원본 열을 계속 사용할 수 있습니다. 미매칭 열을 배치하거나 이미 사용한 열을 다른 표준필드에 다시 놓을 수 있습니다.
미매칭 0개
표준대장에 칸이 없는 원본 열도 버리지 않습니다. 변환 추적정보에는 원본 열과 값이 그대로 보존됩니다. 각 매핑 칸에는 변환 후 데이터의 앞 3건만 미리보기로 표시됩니다. 같은 원본 열을 여러 표준필드에 재사용할 수 있으며, 여러 원본 열을 한 표준필드에 놓으면 기본적으로 공백으로 합쳐집니다. 확정한 매핑과 변환규칙은 프로필에 함께 저장됩니다.

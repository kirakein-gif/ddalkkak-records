# ddalkkak-records

충청남도교육청 기록물 이관·관리·표준화 업무를 하나의 흐름으로 정리하기 위한 웹 기반 프로젝트입니다.

## 목표

이 프로젝트는 기존 Excel/VBA 자동화를 그대로 웹으로 옮기는 것이 아니라, 기록물 업무의 공통 표준 데이터를 중심으로 다음 세 흐름을 연결하는 것을 목표로 합니다.

1. **이관신청 자동화** — K-에듀파인 문서등록대장에서 기록물 이관자료 생성
2. **기록물관리 자동화** — 신규 이관자료 검토, 보존상자 배치, 스티커/상자표지 생성, 기존 대장 통합
3. **기존 대장 마이그레이션** — 지역별로 파편화된 기록물관리대장을 표준양식으로 변환

## 기본 원칙

- 웹은 업무 처리 도구로 사용하고, Excel은 입력·출력 형식으로 유지합니다.
- 가능한 한 파일은 브라우저 안에서 처리하고 서버로 전송하지 않습니다.
- 학교·직속기관·기록관 표준양식을 공통 데이터 모델로 관리합니다.
- 지역별 차이는 프로그램 코드가 아니라 변환 프로필(JSON)로 분리합니다.
- 실제 학교 기록물, 개인정보, 문서 제목 등 민감한 업무자료는 저장소에 올리지 않습니다.
- 테스트 자료는 반드시 익명화한 샘플만 사용합니다.

## 예정 구조

```text
apps/
  transfer/       # 기록물이관
  management/     # 기록물관리
  migration/      # 기존 대장 표준전환
core/
  schema/         # 공통 표준필드
  parser/         # Excel/CSV 읽기
  validator/      # 검증
  exporter/       # Excel 생성
templates/        # 표준양식
profiles/         # 지역별 변환 프로필(JSON)
docs/             # 설계 문서
legacy/           # 기존 Excel 자동화 참고자료
samples/          # 익명화 테스트 자료
```

## 현재 단계

기존 Excel 자동화와 지역별 양식을 분석하여 **표준 데이터 규격과 전체 아키텍처를 확정하는 초기 설계 단계**입니다.

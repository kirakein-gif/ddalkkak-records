# ddalkkak-records

충청남도교육청 기록물 이관·관리·표준화 업무를 하나의 흐름으로 정리하기 위한 웹 기반 프로젝트입니다.

## 목표

이 프로젝트는 기존 Excel/VBA 자동화를 그대로 웹으로 옮기는 것이 아니라, 기록물 업무의 공통 표준 데이터를 중심으로 다음 세 흐름을 연결하는 것을 목표로 합니다.

1. **이관신청 자동화** — K-에듀파인 문서등록대장에서 기록물 이관자료 생성
2. **기록물관리 자동화** — 신규 이관자료 검토, 보존상자 배치, 스티커/상자표지 생성, 기존 대장 통합
3. **기존 대장 마이그레이션** — 지역별로 파편화된 기록물관리대장을 표준양식으로 변환

## 기본 원칙

- 웹은 업무 처리 도구로 사용하고, Excel은 입력·출력 형식으로 유지합니다.
- 가능한 한 파일은 브라우저 안에서 처리하고 서버로 전송하지 않습니다.
- 학교·직속기관·기록관 표준양식을 공통 데이터 모델로 관리합니다.
- 지역별 차이는 프로그램 코드가 아니라 변환 프로필(JSON)로 분리합니다.
- 실제 학교 기록물, 개인정보, 문서 제목 등 민감한 업무자료는 저장소에 올리지 않습니다.
- 테스트 자료는 반드시 익명화한 샘플만 사용합니다.

## 예정 구조

```text
apps/
  transfer/       # 기록물이관
  management/     # 기록물관리
  migration/      # 기존 대장 표준전환
core/
  schema/         # 공통 표준필드
  parser/         # Excel/CSV 읽기
  validator/      # 검증
  exporter/       # Excel 생성
templates/        # 표준양식
profiles/         # 지역별 변환 프로필(JSON)
docs/             # 설계 문서
legacy/           # 기존 Excel 자동화 참고자료
samples/          # 익명화 테스트 자료
```

## 현재 단계

기존 Excel 자동화와 지역별 양식을 분석하여 **표준 데이터 규격과 전체 아키텍처를 확정하는 초기 설계 단계**입니다.


## Cloudflare Pages 배포

- 프로젝트: ddalkkak-records
- 배포 대상 주소: https://ddalkkak-records.pages.dev/
- 운영 브랜치: main
- 프레임워크: None
- 빌드 명령: node scripts/build-cloudflare.cjs
- 출력 폴더: dist
- 빌드 루트: 저장소 루트

cloudflare-public.json에 명시한 실행 파일만 배포합니다. 개발 문서·README·Git 이력은 배포 폴더에서 제외됩니다. Cloudflare GitHub 앱에 이 저장소 접근 권한을 유지하면 비공개 저장소에서도 자동 배포할 수 있습니다. 업무자료는 기존처럼 브라우저에서 처리합니다.

Excel 양식은 같은 Cloudflare 사이트의 /templates/에서 가져옵니다. 공개 raw GitHub 주소에 의존하지 않습니다. 원본 파일의 양식·업무 로직은 그대로 사용하며 빌드 출력에서 호스팅 경로만 조정합니다.

호스팅 어댑터 v1 (2026-10-08): Cloudflare 배포 구성 추가. 프로그램 표시 버전은 v0.9.7 Beta입니다.

### 마이그레이션 중앙 작업방식

마이그레이션은 Cloudflare Pages Functions + D1을 이용해 기록물관리자가 지역별 변환 작업방식을 중앙에서 게시할 수 있도록 구성했습니다.

- 일반 사용자: `/migration/`에서 게시된 작업방식(예: 천안 학교)을 선택
- 기록물관리자: `/migration/master/`에서 작업방식 등록·수정·게시·삭제
- 실제 학교 대장 데이터는 서버에 저장하지 않고 브라우저에서만 처리
- 중앙에는 열 매핑·값 변환·검증 규칙만 저장
- 마스터 진입은 숨은 제스처를 지원하지만 실제 쓰기 권한은 서버 비밀번호 세션으로 보호

D1 스키마와 Cloudflare 설정 방법은 `docs/migration-master.md`를 참고합니다.

저장소 비공개 전환은 새 주소의 실제 기능·파일 다운로드를 확인하고 충교위키 및 기존 북마클릿의 주소 전환을 준비한 뒤 진행합니다. 저장소 비공개와 별개로, 브라우저 실행에 필요한 HTML·JavaScript·표준양식은 서비스 이용자에게 전달됩니다.

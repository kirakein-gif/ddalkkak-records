# 기록물관리 자동화 — 현행 VBA 업무규칙 분석

## 목적

기존 `기록물관리대장 자동화_v19`를 기준으로 이관신청서 취합부터 상자배정·관리번호 부여·기존 대장 통합까지의 규칙을 정리한다.

## 1. 입력

여러 개의 이관신청서 Excel을 동시에 선택하여 취합한다.

이관신청서 11행부터 한 권당 한 행을 읽는다.

현재 가져오는 주요 값:

| 이관신청서 | 신규 작업영역 |
|---|---|
| C3 기관명 | 생산학교 |
| 생산부서 | 생산부서 |
| 기록물철 제목 | 기록물철제목 |
| 문서등록번호 | 문서번호 |
| 시작연도 | 시작년도 |
| 종료연도 | 종료년도 |
| 인계자 성명(L8) | 성명 |
| 표준화 단위과제 | 단위과제 |
| 보존기간 | 보존기간 |
| 공개여부 | 공개여부 |
| 숨김 29열 | 매수 |

숨김 29열의 값은 이관자동화가 계산한 **권 전체 쪽수**이며, 기록물관리 자동화에서는 상자 구성용 `매수`로 사용한다.

## 2. 기존 천안용 분류

현행 프로그램에는 천안 기존 대장에 맞춘 별도 분류가 있다.

### 분류
- 영구 또는 30년 → `1.30년이상`
- 그 외 → `2.한시`

※ 준영구가 장기분류에 포함되지 않는 기존 로직이 있으나, 이는 새 표준 스키마에는 없는 천안 구형 분류이므로 웹버전 Core에는 가져오지 않는다.

### 기록물형태
이관신청서의 기록물형태를 천안용 번호값으로 변환한다.

### 기록물종류
`맞춤` 시트의 제목 키워드/단위과제 규칙으로 졸업앨범, 생활기록부, 졸업대장, 학교회계 등 지역 전용 분류를 만든다.

이 세 값은 **천안 구형 대장용 파생값**이며 새 표준관리대장의 공통 Core 필드와 분리해야 한다.

## 3. 중복검증

현행 신규 취합자료는 다음 조합으로 중복을 검사한다.

```text
문서번호 + 기록물철제목
```

중복이면 양쪽 행을 빨간색으로 표시하고 비고에 `★중복항목 확인`을 기록한다.

웹버전에서는 여기에 관리번호·기관·생산연도 등을 보조 비교값으로 표시하되, 자동 삭제하지 않는다.

## 4. 관리번호

관리번호는 K-에듀파인 문서번호와 무관한 **기관별 자체 기록물 관리번호**다.

현행 규칙:

1. 기존 기록물관리대장의 관리번호를 읽는다.
2. 각 값의 끝자리 숫자부를 추출한다.
3. 가장 큰 번호를 찾는다.
4. 신규 기록물철마다 1씩 증가시킨다.
5. `기관명-00000` 형식으로 부여한다.

기본 시작 기준값은 10000이므로 기존번호가 없으면 첫 신규 번호는 10001이다.

예:
```text
천안버들유-01481
...
천안버들유-10021
```

### 웹버전 개선

현행 VBA는 현재 통합문서가 한 기관이라는 전제로 숫자부 최대값을 찾는다.

웹버전에서는:
- 기관 식별자를 명시적으로 확정
- 해당 기관의 같은 접두부 관리번호만 스캔
- 기존 중복번호 사전검사
- 신규 번호 범위를 한 번에 예약
- 기존 마이그레이션 데이터의 관리번호는 절대 재발급하지 않음

으로 강화한다.

## 5. 보존상자 자동배정

기본 한도:

- 상자당 최대 **1000매**
- 상자당 최대 **8권**
- 같은 상자에는 같은 보존기간만 배치

### 정렬

최초 자동정렬:

1. 보존기간
   - 3년
   - 5년
   - 10년
   - 기타
   - 30년
   - 준영구
   - 영구
2. 과제카드명
3. 권차 숫자

### 상자번호 접두부

- 영구 / 준영구 / 30년 → 보존기간을 접두부로 사용
- 그 외 한시 기록물 → 생산연도를 접두부로 사용

예:
```text
2025-01
2025-02
30년-01
준영구-01
영구-01
```

기존 대장에 같은 접두부의 상자가 있으면 최대 일련번호 다음부터 이어간다.

### 다음 상자로 넘어가는 조건

다음 중 하나면 새 상자를 시작한다.

- 사용자가 수동 `상자분할` 지정
- 보존기간 변경
- 8권 초과
- 누적 1000매 초과

### 자동 제외

설정된 기록물형태/철제목 키워드에 해당하면 상자구성에서 제외한다.

기본 폴백 예:
- 형태: 도면
- 제목: 지출증빙, 회계증빙, 반환결의, 수입일계표, 징수부, 수납결의, 반납결의, 징수결의

이 규칙은 지역·기관별로 달라질 수 있으므로 Core에 하드코딩하지 않고 **관리 프로필**로 분리한다.

## 6. 기존 대장 통합

신규 작업영역의 각 내부 키를 선택된 대장양식의 키와 매칭해 복사한다.

충남 표준양식일 경우 추가로:
- 기관명을 전체기관명으로 정규화
- 기관명에서 기관코드 수식 생성
- 단위과제명을 표준 단위과제표 기준으로 보정
- 순번 수식 생성
- 표준 유효성검사 연결

## 7. 새 표준으로 옮길 때 바로잡을 의미 차이

### 기관명과 내부부서명

현행 `신규`에서는:
- 생산학교 → `keepOrgNm`
- 생산부서 → `creatOrgNm`

로 매핑한다.

그러나 새 표준의 `keepOrgNm/creatOrgNm`은 기관코드표에서 코드를 찾는 필드다. 학교의 `행정실` 같은 내부 부서명은 기관코드 조회 대상이 아니다.

따라서 웹 Core에서는 다음처럼 분리한다.

```text
institution.current
institution.creator
transfer.departmentName
```

학교의 경우 표준 기관명 필드에는 전체기관명을 사용하고, `행정실` 같은 내부 처리과는 이관업무 컨텍스트로 별도 보존한다.

### 공개구분

현행 신규영역에는 `비공개(6호)` 같은 결합 문자열이 들어온다.

표준관리대장에서는:
- 공개구분 = 비공개
- 비공개호수 = 6호

로 분리한다.

### 기록물유형

기존 천안용 `기록물형태` / `기록물종류`는 표준의
- 기록유형
- 세부유형
- 매체유형

과 동일한 개념이 아니다. 지역별 구형 필드는 migration profile에서 해석하고 Core 표준필드로 변환한다.

## 8. 관리단계에서 생성되는 값

문서등록대장이나 이관신청서에 없어도 정상인 값:

- 관리번호
- 상자번호
- 물리적 위치정보
- 기록물상태
- DB등록여부
- 기록관 배치정보

이 값들은 **이관자료의 결손이 아니라 관리단계에서 새로 생기는 데이터**다.


## 웹버전 보완 — 다기관 상자분리

기존 VBA 상자 자동배정은 보존기간/생산연도 접두어를 기준으로 상자 일련번호를 관리하며,
상자 배정 키에 기관명이 직접 포함되지 않는다.

여러 기관의 이관신청서를 한 번에 취합하는 웹버전에서는
서로 다른 기관의 기록물이 같은 상자 그룹으로 계산되지 않도록 다음을 기본 규칙으로 한다.

```text
상자 그룹 키 = 기관 + 접두어 + 보존기간
```

실제 상자번호 표시값은 기존 규칙처럼 유지할 수 있다.

- 3년/5년/10년 등 한시 → 생산연도-일련번호
- 30년/준영구/영구 → 보존기간-일련번호

단, 내부 계산 카운터는 기관별로 독립한다.

같은 기관 안에서도 한 상자에는 같은 보존기간만 넣고,
8권 또는 1000쪽을 초과하면 다음 상자를 시작한다.

수동 상자분할과 상자제외를 지원하며,
사용자가 순서를 바꾸면 상자번호를 다시 계산한다.


## 관리번호 자동부여 구현 메모

예시 `기록물관리대장(천안버들유).xlsx`을 분석한 결과:

- 기존 관리번호 접두어: `천안버들유`
- 기존 행 수: 1,339건
- 숫자부 최대값: `10223`
- 따라서 신규 시작번호: `천안버들유-10224`
- 기존 대장에는 과거 중복 관리번호가 존재하므로 신규 부여 시 단순 행번호가 아니라 **기관별 동일 접두어 숫자부 최대값 + 1**을 사용한다.

신규 기관처럼 기존 관리대장이 없는 경우:

- 기준값 10000
- 첫 신규번호 10001
- 접두어는 기관명으로 자동 제안하되 사용자가 1회 확인

예:
- 샘플가람유치원 → `샘플가람유-10001`

### 관리번호 부여 순서

1. 기관 식별
2. 해당 기관 기존 관리대장 분석
3. 관리번호 접두어 탐지
4. 숫자부 최대값 탐지
5. 기존 중복 여부 경고
6. 신규 기록물철에 최대값+1부터 연속 부여
7. 신규번호 중복검사
8. 사용자가 최종 확정

기존 번호는 절대 재발급하거나 재정렬하지 않는다.


## 웹버전 업무경계 확정 — 위치정보 제외

기록물관리 자동화의 핵심 처리범위는 다음까지로 한다.

1. 이관신청서 수신·검증
2. 기록물철 취합
3. 보존상자 자동집계·상자번호 부여
4. 기관별 관리번호 부여
5. 표준 기록물관리대장 생성

다음 물리적 위치정보는 이 단계에서 자동화하지 않는다.

- 서고
- 서가
- 열
- 층
- 위치번호
- 기타 실제 배치정보

이 값들은 보존상자를 실제 장소에 배치한 뒤 발생하는 관리정보이므로
표준관리대장 출력 시 공란으로 두고 이후 실물 배치 업무에서 보완한다.

상자번호는 기록물관리 자동화에서 확정한다.

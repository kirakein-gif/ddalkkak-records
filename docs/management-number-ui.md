# 관리번호 자동부여 UI v0.1

## 목적

상자배정이 끝난 신규 기록물철에 기관별 관리번호를 자동 부여한다.

## 테스트 자료

- 천안버들유치원 신규 222권
- 샘플가람유치원 신규 14권
- 총 236권

천안버들유치원 기존 관리대장을 실제 분석한 결과:

- 기존 관리번호 접두어: 천안버들유
- 기존 행 수: 1,339
- 숫자부 최대값: 10223
- 신규 시작번호: 천안버들유-10224

샘플가람유치원은 기존 대장이 없는 상황으로 가정:

- 제안 접두어: 샘플가람유
- 신규 시작번호: 샘플가람유-10001

## UI 기능

- 기관별 기존 관리대장 연결상태 표시
- 관리번호 접두어 자동탐지/수정
- 기존 최대번호 표시
- 신규 시작번호 미리보기
- 신규 기록물철 관리번호 일괄 부여
- 제목·단위과제·관리번호 검색
- 기관 필터
- 수기수정 등 확인사항만 보기
- 관리번호 확정 후 위치정보 단계로 이동

## 안전장치

- 기존 번호는 보존
- 기관별 번호 시퀀스 분리
- 기존 관리번호 중복이 있어도 최대 숫자 이후부터 신규 부여
- 신규 관리번호 자체의 중복검사를 최종 출력 전에 다시 수행
- 기존 관리대장이 없는 기관은 10001부터 시작하되 접두어 확인 필수

# 기록물관리 자동화 버전 이력

## 버전 정책

베타 기간에는 화면 우측 상단에 `v0.MINOR.PATCH Beta`를 항상 표시한다.

- 작은 오류 수정, UI 보정, 출력 호환성 수정: PATCH 증가
  - 예: `v0.7.1 → v0.7.2`
- 기능 묶음이나 처리 단계가 크게 추가·변경될 때: MINOR 증가 후 PATCH를 0으로 초기화
  - 예: `v0.7.9 → v0.8.0`
- 배포하지 않은 내부 수정은 버전을 올리지 않는다.
- 사용자가 테스트할 수 있는 GitHub Pages 배포본이 바뀔 때 버전을 올린다.

# 딸깍 기록물관리 Beta 테스트 계획

기준일: 2026-09-23

## 목적

현재 단계는 완성품 선언이 아니라 실제 업무 파일을 사용하여 다음을 검증하는 단계다.

1. 원본 데이터가 누락·변형 없이 읽히는지
2. 자동화 규칙이 실제 업무와 맞는지
3. 생성 Excel이 Microsoft Excel에서 복구경고 없이 열리는지
4. 이관신청서 → 기록물대장관리 연계가 끊기지 않는지
5. 표지·색인·관리번호 스티커·상자라벨이 원본 출력양식을 보존하는지

## Beta 모듈

### 기록물이관신청서 v0.2 Beta
- 문서등록대장 Excel/CSV 업로드
- 비전자 대상 검증
- 기록유형 1차 자동분류 및 사용자 보정
- 일반문서 100쪽 기준 자동편철
- 일반문서 외 1문서 = 1권
- 제외/복원, 순서 보정, 수동 분권
- 이관 Excel 생성
- 숨김 _handoff / _handoff_docs 생성

최우선 검증:
- 실제 K-에듀파인 문서등록대장의 열 인식
- 기록유형 오분류
- 100쪽 분권 경계
- 생성 Excel 열기
- 기록물대장관리에서 _handoff 연계

### 기록물대장관리 v0.6.2 Beta
- 이관신청서 다중 취합
- 승인된 편철 결과 유지
- 기관별 프로필
- 보존상자 자동제외 규칙
- 보존기간 동일, 최대 8권, 최대 1000쪽 기준 상자배정
- 기존 관리번호 보존 + 신규 관리번호 부여
- 최종 철제목 재번호
- 원본 Excel 템플릿 기반 표지/색인/관리번호 스티커/상자라벨 출력

최우선 검증:
- 실제 이관자료 누락 여부
- 상자 경계/자동제외 결과
- 기존·신규 관리번호 연속성
- 4종 출력 Excel의 형식/인쇄미리보기

### 기존 대장 마이그레이션 v0.5 Beta
- 지역/기관별 기존 기록물관리대장 입력
- 헤더/시트 자동탐지
- 자동매핑 + 드래그 보정
- 같은 원본열 다중 재사용
- 나누기/자르기/치환/합치기
- 3건 변환 미리보기
- 매핑/변환 프로필 저장
- 원본값/출처/미사용열 추적

최우선 검증:
- 공주/금산/천안/아산/서산 등 실제 양식별 헤더 인식
- 기존 관리번호·상자번호·위치정보 보존
- 누락 표준필드가 임의 추정되지 않는지
- 출력 Excel 복구경고 여부

## 아직 Beta 범위 밖

- 표준 기록물관리대장(학교/직속/기록관) 최종 출력
- 표지/색인의 프린터별 미세 위치조정
- 이관신청서 결재 표시양식 최종 고정
- 모든 지역 마이그레이션 예외규칙 사전 하드코딩

## 실제 파일 테스트 원칙

- 원본 유일본은 사용하지 않고 복사본으로 시작한다.
- 생성 결과를 원본과 대조한다.
- 생성된 모든 Excel은 Microsoft Excel에서 다시 연다.
- Excel 복구경고가 발생하면 해당 파일을 그대로 보관하고 원인 분석 대상으로 남긴다.
- 이관신청서 출력은 기록물대장관리 입력으로 연속 테스트한다.
- 출력물은 화면 확인만 하지 않고 인쇄미리보기까지 확인한다.

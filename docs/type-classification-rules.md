# 기록유형 3단계 자동판정 설계 v0.1

## 문제

문서등록대장에는 표준 기록물관리대장의 다음 3개 필드가 없다.

- 기록유형
- 세부유형
- 매체유형

따라서 이관신청 단계에서 생성해야 한다.

3개를 각각 독립적으로 추정하지 않고 표준 유효성 구조에 맞춰 계단식으로 판정한다.

## 표준 분류구조

### 기록유형
- 문서류
- 시청각류

### 문서류 세부유형
- 일반문서
- 대장
- 카드
- 도면

문서류 매체 후보:
- 종이
- 사진
- 필름
- 자기매체
- 광매체
- 기타

### 시청각류 세부유형
- 사진
- 영상
- 음성

사진 매체 후보:
- 인화사진
- 슬라이드필름
- 필름
- 사진CD
- 사진DVD
- 기타

영상·음성은 표준서식의 종속 유효성목록 범위에 맞춰 후보를 제한한다.

## 자동화 핵심 원칙

### 1. 일반 기록은 기본값

편철 대상은 전부 비전자 기록물이다.

특수기록을 나타내는 강한 증거가 없으면:

문서류 → 일반문서 → 종이

를 기본 제안한다.

이 값은 문서등록대장의 대부분을 자동처리하기 위한 기본경로다.

### 2. 특수기록 후보만 탐지

문서 제목을 중심으로 다음 신호를 탐지한다.

강한 예:
- 도면
- 사진철 / 현장사진 / 공사사진 / 사진대지
- 필름 / 슬라이드
- DVD / 비디오테이프 / 비디오릴
- 녹음테이프 / 오디오CD / DAT
- 사진CD / 사진DVD

보조 신호:
- 과제카드명
- 과제명
- 표준 단위과제명
- 표준 단위과제 업무설명/편철예시

### 3. 단순 포함검색을 사용하지 않는다

제목에 '사진'이라는 단어가 있다고 모두 사진 기록으로 판정하면 안 된다.

예:
- 사진 촬영 동의서
- 사진 제출 안내
- 졸업사진 촬영 계획

이런 제목은 종이 일반문서일 가능성이 높다.

따라서 키워드와 주변 표현을 함께 본다.

예:
- "사진 촬영 동의서" → 일반문서 후보
- "행사 현장사진" → 사진 후보
- "공사 전·후 사진대지" → 사진 후보
- "DVD 구입 계획" → 일반문서 후보
- "행사 영상 DVD" → 영상/DVD 후보

## 2단계 판정

### 문서 단위 1차 판정

편철 전에 각 문서에 임시 유형힌트를 부여한다.

- NORMAL
- DRAWING
- PHOTO
- VIDEO
- AUDIO
- CARD_CANDIDATE
- LEDGER_CANDIDATE
- UNKNOWN_SPECIAL

이 힌트는 특수기록을 일반문서와 분리 편철하기 위한 용도다.

### 기록물철 단위 최종 판정

편철이 끝난 후 각 기록물철에 최종 3종 값을 만든다.

예:
- NORMAL → 문서류 / 일반문서 / 종이
- DRAWING + 종이 신호 → 문서류 / 도면 / 종이
- PHOTO + 인화사진 신호 → 시청각류 / 사진 / 인화사진
- PHOTO + 사진CD → 시청각류 / 사진 / 사진CD
- VIDEO + DVD → 시청각류 / 영상 / DVD
- AUDIO + 오디오CD → 시청각류 / 음성 / 오디오CD

## 확신도 정책

### 자동확정
명확한 조합만 자동확정한다.

예:
- 사진CD
- 사진DVD
- 비디오테이프
- 녹음테이프
- 오디오CD
- 도면 + 종이 문맥

### 자동제안 + 사용자확인
세부유형은 강하지만 매체가 불명확한 경우.

예:
"2025학년도 체육대회 사진"

제안:
- 기록유형: 시청각류
- 세부유형: 사진
- 매체유형: 확인 필요

사용자는 매체유형만 고른다.

### 일반문서 기본처리
특수 신호가 없으면 자동으로:

문서류 / 일반문서 / 종이

사용자가 일일이 확인하지 않는다.

### 애매한 표현
특수 키워드가 업무대상/계획/구입/동의서의 의미로 사용된 경우에는 일반문서로 유지하되 "유형 후보" 표시가 가능하다.

## UI

편철화면에서 일반 기록물은 3개 필드를 노출하지 않아도 된다.

예:
[일반문서 · 종이]  자동

특수 후보에만 경고카드를 표시한다.

예:
제목: 졸업식 행사 사진
추천:
기록유형   시청각류  ✓
세부유형   사진      ✓
매체유형   [인화사진 ▼]  확인 필요

[이 유형을 같은 제목 패턴에 적용]

## 반복 학습

사용자가 한 번 수정한 규칙을 해당 작업 안에서 즉시 재사용한다.

예:
"현장체험학습 사진"을 사진/인화사진으로 확정하면
유사한 제목에 같은 추천을 적용한다.

장기적으로는 지역/기관 프로필에 사용자 정의 키워드 규칙을 저장할 수 있다.

AI 모델의 자유판단보다 설명 가능한 규칙엔진을 우선하고,
AI는 규칙으로 결정하기 어려운 후보를 추천하는 보조수단으로 둔다.

## 중요 주의

### 대장
제목에 '대장'이 있다고 무조건 세부유형 '대장'으로 자동확정하지 않는다.
업무명이나 기록물 제목에서 '대장'이라는 단어가 의미적으로 사용될 수 있으므로 실제 표준 적용기준을 추가 확인한 뒤 자동화 범위를 결정한다.

### 카드
'카드' 역시 과제카드 등 시스템 용어와 혼동될 수 있다.
따라서 문서제목의 실제 기록매체를 뜻하는 경우만 후보로 잡는다.

## 목표

대부분의 기록:
문서류 / 일반문서 / 종이 자동처리

소수의 특수기록:
제목+과제정보로 후보 탐지 → 3단계 연쇄판정 → 불확실한 마지막 단계만 사용자 확인

즉 사용자가 모든 기록물에 3개 항목을 입력하는 구조가 아니라,
특수기록 몇 건만 확인하는 구조로 만든다.

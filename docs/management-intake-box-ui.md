# 기록물관리 수신·취합·상자배정 UI v0.1

## 처리 흐름

```text
이관신청서 여러 개
→ _handoff current 읽기
→ 패키지 검증
→ 기록물철 취합
→ 기관별 상자 자동배정
→ 관리번호 부여
→ 위치정보
→ 표준 기록물관리대장
```

## 수신 검증

- schemaVersion 확인
- transferPackageId 중복 확인
- rowId 무결성 확인
- validationState 확인
- userModified 표시
- 수기수정은 정상적인 current 값으로 취합
- 동일 packageId 재업로드는 자동 제외

## 상자 자동배정

기본 기준:

- 기관 혼합 금지
- 동일 상자에는 동일 보존기간만
- 최대 8권
- 최대 1000쪽
- 3/5/10년 등 한시 기록물 상자번호 접두어 = 생산연도
- 30년/준영구/영구 접두어 = 보존기간
- 기존 기록물관리대장의 같은 접두어 최대 일련번호 다음부터 시작

정렬 기준:

1. 기관
2. 보존기간 순위
3. 단위과제
4. 권차

사용자 보정:

- 드래그 순서조정
- 여기서 새 상자 시작
- 상자배정 제외/복원
- 자동배정으로 되돌리기

순서조정은 같은 기관·같은 보존기간 안에서만 허용한다.

## UI 테스트

`기록물관리_수신취합_상자배정_UI_테스트.html`에서 다음을 검증한다.

- 실제 v2 handoff 222권 취합
- 별도 샘플 기관 14권 취합
- 동일 packageId 재업로드 중복차단
- userModified 표시
- 기관별 상자 독립배정
- 8권/1000쪽 자동분할
- 수동 상자분할/제외
- 상자배정 확정 후 관리번호 단계로 이동

현재 HTML은 UX와 업무규칙 테스트용이며 실제 xlsx 업로드 파서는 다음 구현 단계에서 연결한다.

## v0.6.3 Beta — 2026-10-02

유효성검사 보정:
- 실제 마이그레이션 결과파일을 검사해 N열 세부유형과 O열 매체유형의 종속 드롭다운 수식 오류 확인
- N열: `INDIRECT("철세부유형_"&$M5)`로 수정
- O열: `INDIRECT("철매체유형_"&$M5&"_"&$N5)`로 수정
- S열 보존장소에 `기록관 / 처리과` 드롭다운 적용
- L 보존기간, M 기록유형, Q 공개구분, T 열람구분, W 서고, AD 기록물상태, AE DB등록여부도 최종 행까지 재적용
- 기존 중복 유효성검사 블록은 출력 시 제거하고 정상 규칙 하나로 재생성
- `2.도면` 같은 구형 번호 접두어를 제거해 `도면`으로 표준화하고 기록유형=문서류, 매체유형=종이 계층 보정
